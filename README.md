# CodeVeda Data Analytics Internship

This repository contains the completed tasks for the CodeVeda Data Analytics Internship. The work includes data cleaning, exploratory data analysis, regression analysis, time series analysis, classification modeling, and sentiment analysis.

## Repository Structure

### Level 1
- **Task 1: Data Cleaning**
  - Imported the house prediction dataset.
  - Checked columns, missing values, and data types.
  - Cleaned and modified the dataset.
  - Saved the cleaned dataset.

- **Task 2: Exploratory Data Analysis**
  - Performed analysis on the cleaned house prediction dataset.
  - Used summary statistics and visualizations.
  - Identified important data patterns.

### Level 2
- **Task 1: Regression Analysis**
  - Built a regression model using the cleaned house prediction dataset.
  - Trained and evaluated the model.
  - Created regression output visualization.

- **Task 2: Time Series Analysis**
  - Imported stock price data.
  - Analyzed stock price trends over time.
  - Visualized time series patterns.

### Level 3
- **Task 1: Classification Model**
  - Imported the churn dataset.
  - Encoded categorical values.
  - Scaled features and trained a classification model.
  - Evaluated model performance.

- **Task 2: Sentiment Analysis**
  - Imported the sentiment dataset.
  - Cleaned and processed text data.
  - Built a sentiment analysis model using NLP techniques.
